# 🎓 TAG Timetable Bot

Telegram бот для просмотра расписания [TAG](https://tag.edupage.org/timetable/).

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![python-telegram-bot](https://img.shields.io/badge/python--telegram--bot-21.0.1-blue.svg)](https://python-telegram-bot.org/)
[![License](https://img.shields.io/badge/license-GPL-green.svg)](LICENSE)

## ✨ Возможности

- ✅ **Без авторизации** - работает через публичный API EduPage
- 📚 **Текущий урок** - показывает что идёт сейчас
- 📅 **Расписание на день** - полное расписание с кабинетами
- 🔔 **Расписание звонков** - с подсветкой текущего урока
- 👥 **Групповые чаты** - личные и глобальные классы
- 💾 **Сохранение настроек** - переживает перезапуск
- 🌐 **Поддержка групп** - деление на подгруппы (английский, русский и т.д.)

## 🚀 Подготовка

### Требования

- Python 3.8+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

1. **Клонировать репозиторий:**
```bash
git clone https://github.com/yourusername/tag-timetable-bot.git](https://github.com/OtVaL228/TAG_EduPage.git
cd TAG_EduPage
```

2. **Установить зависимости:**
```bash
pip install python-telegram-bot==21.0.1 pytz requests
```

3. **Настроить токен:**
```bash
# Открыть bot_final.py и вставить токен
nano bot_final.py

# Найти строку:
TELEGRAM_TOKEN = "TELEGRAM TOKEN HERE"

# Заменить на ваш токен:
TELEGRAM_TOKEN = "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
```

4. **Запустить бота:**
```bash
python3 bot_final.py
```

## 📖 Использование

### Личный чат

```bash
/start           # Главное меню
/setclass G3k    # Установить класс
/schedule        # Расписание на сегодня
/current         # Текущий урок
/bells           # Расписание звонков
```

### Групповой чат

#### Для всех участников:
```bash
/setclass G3k    # Установить личный класс
```

#### Для администраторов:
```bash
/setclassglobal G3a     # Установить глобальный класс
/toggleglobal           # Включить/выключить глобальный класс
```

### Естественные запросы

Бот понимает обычные вопросы на русском:
- "Какой сейчас урок?"
- "Расписание на сегодня"
- "Расписание звонков"

## 🔧 Конфигурация

### Структура настроек

Настройки сохраняются в `bot_settings.json`:

```json
{
  "user_settings": {
    "123456": {
      "class": "G3k"
    }
  },
  "group_settings": {
    "-1001234567890": {
      "global_class": "G3a",
      "global_enabled": true,
      "user_classes": {
        "111111": "G3b",
        "222222": "G3c"
      }
    }
  }
}
```

### Приоритет классов в группах

1. **Личный класс** пользователя в группе
2. **Глобальный класс** чата (если включён)
3. Класс не установлен

## 📋 Доступные классы

## 🏗️ Архитектура

### Основные компоненты

```python
TAGTimetableAPI
├── get_timetable_data()           # Загрузка из EduPage API
├── get_class_schedule_for_day()   # Расписание класса
└── [кэширование 5 минут]

TimetableBot
├── Команды (/start, /setclass, /schedule, ...)
├── Callback handlers (кнопки)
├── Триггеры (естественные вопросы)
└── Сохранение настроек (bot_settings.json)
```

### API Endpoint

Бот использует публичный endpoint EduPage:
```
POST https://tag.edupage.org/timetable/server/regulartt.js?__func=regularttGetData
Body: {"__args": [null, "442"], "__gsh": "00000000"}
```

## 🐛 Устранение неполадок

### Бот не отвечает
```bash
# Проверить токен
grep TELEGRAM_TOKEN bot_final.py

# Проверить логи
python3 bot_final.py
```

### Настройки не сохраняются
```bash
# Проверить права на запись
ls -la bot_settings.json

# Проверить синтаксис JSON
python3 -m json.tool bot_settings.json
```
